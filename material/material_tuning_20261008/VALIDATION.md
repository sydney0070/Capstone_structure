# 실행·구현 검증 기록

검증일 2026-10-08. Python 3.12, OpenSeesPy 3.8.0.0 / OpenSees 3.8.0, macOS 환경에서 수행했다. **실제 지반·구조재의 실험 검증 또는 전체 돔의 안전성 검증은 아니다.**

## 실행 확인

- 23개 기본 시편 실행 및 CSV·PNG·설정·요약 저장 완료: `results/`, `all_runs.log`.
- 13개 구현 검사 통과: `verify.py`, `verification.log`.
- 9개 비선형/접촉 시편에서 재하 증분을 절반으로 줄여 비교: `check_refinement.py`, `refinement_checks.json`.
- Steel02 합성자료의 학습·독립 진폭 검증 및 두 매개변수 회수 완료: `synthetic_demo/fitted/fit_report.json`.

13개 검사는 탄성 전단 Gγ와 반력, Concrete02 압축 피크, 탄성 쉘의 E 및 포아송 수축, 금속의 탄성 구간, 직교이방성 축강성, 마찰의 전체 stick/slip/하중반전 경로와 수직 평형, gap의 무인장·압축 항복, 비선형 점성 법칙, 말뚝 용량 단위 환산, 행성 자중응력, 지반 평형·변위, PM4 응력 감소 출력의 의미, 일부 잘못된 입력의 거부를 확인한다. 정답을 구현과 똑같이 복사한 비교가 아니라 해석해·평형·별도 힘 법칙을 기준으로 삼았다.

체적변형률 및 PM4의 `ru_equivalent` 차이도 JSON에 별도 기록했다. 단일 요소의 이 검사는 전체 지반 메시, 큰 변형, 고주파 동적 해석, 전체 좌굴 또는 모든 가능한 튜닝값의 수렴을 증명하지 않는다.

검증 중 선택을 변경한 항목도 기록한다. 초기 u–p PM4 시편은 증분 변화에 안정적이지 않아 배포 코드에서 제외했고, 재료 시험용 정적 일정체적 `SSPquad`로 검증했다. 실제 간극수압 DOF가 없으므로 수압·CRR 보정 완료로 해석하면 안 된다. 접촉은 기존 `zeroLengthContact2D`를 사용한 시편의 commit 후 힘 조회에서 큰 경로 차이가 나타나, 배포 버전을 `zeroLengthContactASDimplex`의 implicit 적분으로 바꾸고 전체 마찰 경로와 세분화 검사를 통과시켰다. 이는 이 시편·출력 경로에서의 관찰이며, 다른 해석의 해당 요소까지 일반적으로 잘못되었다는 결론은 아니다.

## 자동 보정 회수 시험

`make_demo.py`가 OpenSees로 생성한 **합성자료**를 사용했다. 진값은 Fy=380,000 kPa, b=0.015이며, 학습 진폭 0.005와 검증 진폭 0.008을 분리했다. 초기 후보는 Fy=400,000 kPa, b=0.01이고, 나머지 Steel02 인자는 고정했다.

| 항목 | 결과 |
|---|---:|
| 회수 Fy | 379,999.99873 kPa |
| 회수 b | 0.01500000051 |
| 학습 NRMSE | 8.93×10⁻¹⁰ |
| 검증 NRMSE | 8.69×10⁻¹⁰ |
| 최적화 종료 | 성공 |
| 탐색 중 실패 예시 | 없음 |

동일한 구성모델로 생성한 자료이므로 작은 오차가 예상되는 시험이다. 최적화·단위·재하 이력 보존 기능의 확인이며, 실제 철근에 대한 적합성이나 매개변수의 일반적 유일성은 확인하지 않는다.

## 재실행

README의 환경 설치 후 다음을 실행한다.

```bash
python verify.py
python check_refinement.py
python tune.py all --out my_results/recheck
python make_demo.py
python tune.py fit --config synthetic_demo/starting_config.json --targets synthetic_demo/targets.json --maxiter 40 --out my_results/fit
```

`results/`의 기본값 대부분은 예시 가정이다. 취성 쉘 4종은 탄성 강성만, CFRP는 축이 정렬된 직교이방성만 확인했다. RC 보·기둥 조립 보조 함수는 확장용 예시로, 이 23개 시편이나 별도의 RC 구조 실험 검증에 포함되지 않는다. 실제 돔·하이퍼볼로이드에서는 기하비선형·메시·좌굴·접촉 개폐·환경·내압·질량과 기초 조건을 별도로 검증해야 한다.
