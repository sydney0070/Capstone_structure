# 2단계: 재료 시편에서 구조물 비교 모델로 연결

작성일 2026-10-12. 이전 단계의 재료별 튜닝 코드 다음에 필요한 작업을 검토하여 **전체 형상·하중·지지 조건을 가진 탄성 기준 모델**을 추가했다. 실제 치수와 실험자료가 아직 전달되지 않아 아래 형상과 기초 강성은 모두 임시값이다.

## 이번에 진행한 작업

1. 닫힌 상부를 가진 구면 캡 돔과 상·하단이 열린 회전 하이퍼볼로이드의 4절점 쉘 메시 생성.
2. 재료 시편의 E·ν·ρ를 구조물 입력에 연결. 금속도 이번 단계에서는 초기 탄성 강성만 비교.
3. 같은 형상·두께·재료·지지 강성에서 지구/달/화성의 중력만 변경.
4. 하부 병진 구속과 선형 분포 스프링을 비교. 두 조건 모두 구조물의 회전 자유도는 구속하지 않음.
5. 질량·자중·압력 적분·반력 평형·중력 비례·강성 비례·메시 세분화 검증.
6. 별도의 돔 압력 예제에서 기초 인장 지지력 요구량을 출력.

각 재료의 시편이 실행된 것만으로 전체 구조 조립·질량·하중·SSI 연결이 올바르다고 볼 수 없기 때문에 이 단계를 먼저 수행했다. 기존 프로젝트의 환경 예제는 N–m–kg 단위이고 이번 패키지는 kN–m–tonne 단위이므로 그대로 혼합하지 않았다.

## 가정과 구현

| 항목 | 임시 설정 |
|---|---|
| 돔 | 기저 반지름 5 m, 솟음 2.5 m의 구면 캡; 꼭대기 구멍 없음 |
| 하이퍼볼로이드 | 높이 6 m, 상·하단 반지름 5 m, 중앙 목 반지름 3 m; 개방 상단 |
| 두께 | 모든 재료 0.02 m; 두께의 설계 적합성을 의미하지 않음 |
| 재료 | 강재·알루미늄·콘크리트·소결 레골리스·지오폴리머·황콘크리트, 총 6개 |
| 주 비교 하중 | 구조 쉘 자중만. 지구/달/화성 g=9.81/1.62/3.71 m/s² |
| 하부 병진 구속 | `pinned`: x/y/z 고정, 회전 자유; 완전 고정단과 다름 |
| 선형 지반 대용 | `linear_springs`: 둘레 길이당 수평 10,000, 수직 20,000 kN/m² |
| 스프링 절점 강성 | 위 값 × 담당 둘레 길이(m) → kN/m; 메시 증가 시 총 강성 유지 |
| 비교 메시 | n=48. 돔 48×48=2,304 요소; 하이퍼볼로이드 192×48=9,216 요소 |
| 압력 보조 예제 | 알루미늄 돔 외향 압력차 1 kPa; 거주 요구압력 가정 아님 |

기초 강성은 실제 지구·달·화성의 보정값이 아니다. **이번 행성 비교는 중력 효과만 분리**하며, 이전 DP/PDMY 지반 시편을 구조물 아래 연속체로 연결한 모델이 아니다. 현재 스프링은 선형·양방향이라 인장도 전달한다. `required_hold_down_kN > 0`이면 앵커 등 인장 지지가 필요하다는 신호이며, 무앵커 접촉의 성능을 나타내지 않는다. 실제 접촉 개폐·미끄럼·링기초 강성은 다음 단계다.

쉘에는 `ElasticMembranePlateSection`과 `ShellMITC4`를 사용했다. 3D/6DOF이고 작은 변형의 탄성 기준선이다. 선형 스프링은 `Elastic` uniaxial + `zeroLength`이다. 근거: [공식 쉘](https://openseespydoc.readthedocs.io/en/latest/src/ShellMITC4.html), [탄성 단면](https://openseespydoc.readthedocs.io/en/latest/src/elasticMembranePlateSection.html), [zeroLength](https://openseespydoc.readthedocs.io/en/latest/src/ZeroLength.html).

곡면의 2×2 가우스 적분으로 절점 담당 면적과 압력 벡터를 산정했다. ρ×두께×담당 면적으로 질량을 만들고, 질량에 행성 중력을 곱해 자중을 적용한다. 관성 질량은 절점에 한 번만 부여한다. 압력은 초기 형상의 법선 방향 분포하중이며 follower load가 아니다. 돔 바닥판·폐쇄 압력용기의 압력 평형까지 구현하지 않았다. 개방 하이퍼볼로이드에는 압력 입력을 거부한다.

CFRP는 국부 섬유 방향·적층 정보가 없어 이번 전체 곡면 비교에서 제외했다. 임의의 요소 방향을 섬유 방향으로 간주하면 메시 방향에 따라 결과가 달라질 수 있다. 기존 CFRP 시편은 계속 사용할 수 있다.

## 실행

상위 README의 Python 환경 설치 후 이 폴더에서 실행한다.

```bash
python model.py --config prototype_config.json --out my_results/dome
python verify_structure.py
python compare.py
python report.py
```

- `model.py`: 설정 한 개 실행. `prototype_config.json`의 형상, 두께, 하중, 중력, 스프링 강성 수정.
- `compare.py`: 72개 자중 시나리오 + 압력 예제 3개 실행, 비교 그림 작성. 출력은 같은 경로에 갱신되므로 기존 결과를 보관하려면 먼저 복사.
- `verify_structure.py`: 독립 역학 관계와 메시 검증. 실패하면 종료 코드 2.
- `report.py`: 저장된 결과에서 한국어 결과 요약 생성.
- `results/*/config.json`, `summary.json`, `model_arrays.npz`: 입력, 요약, 좌표/연결/변위/하중/반력/절점 질량.
- [결과 요약](RESULTS_KO.md), [비교 그림](comparison.png), [형상 그림](geometry.png), [검증 원자료](verification.json).

튜닝 결과를 연결하려면 설정의 `material_config`에 해당 재료 JSON 경로를 지정한다. 상대 경로의 기준은 상위 `material_tuning_20261008` 폴더다. 예: `configs/shell_aluminum.json` 또는 보정된 `best_config.json`. `material` 이름과 단위가 일치해야 한다. **이 단계에서는 E·ν·ρ만 가져오고 항복·경화·균열 인자는 사용하지 않는다.** `material_override`는 별도의 민감도 입력으로 우선 적용되며, 실제 사용된 값은 `summary.json`에 기록한다.

## 다음 작업의 순서와 필요한 입력

| 순서 | 해야 할 일 | 완료에 필요한 입력 |
|---|---|---|
| 1 | 실제 캡스톤의 기준 형상·하중 확정 | 쉘/격자 구조 선택, 지름·높이·두께, 개구부, 내부 압력차, 차폐층, 링/앵커/기초 방식 |
| 2 | 재료 실험자료를 시편에 보정 | 재료 등급/배합, 밀도·제조/온도 조건, 압축·인장·반복 시험의 원시 곡선 |
| 3 | 행성별 지반 시나리오 정의·보정 | 시뮬런트명, 밀도/간극비, 깊이·성층, 낮은 구속압 전단·체적변형 자료 |
| 4 | 기초의 침하·미끄럼·들뜸을 구조물과 결합 | 기초 치수, 정상력별 접촉 전단시험, 압축 침하곡선, 앵커 존재·성능 |
| 5 | 후보별 비선형·좌굴 검증 및 공정한 비교 | 초기 결함, 적층/배근, 파괴 자료, 제조 조건; 동일 질량/성능 비교 기준 |

입력 정리 양식은 `experiment_inventory.json`이다. 비어 있는 칸은 미확보 자료를 뜻한다. 실험자료가 들어오기 전에는 임의 물성을 ‘보정 완료’로 바꾸지 않는다. 이번 결과의 최대 변위·질량만으로 최적 소재를 결정하지 않으며, 안전율·좌굴 하중·파괴강도를 산출했다고 해석하지 않는다.
