# 재료 선정·튜닝 작업 최종 보고 — 2026-11-02

## 결론

구조물 형상이 없는 상태에서 준비할 수 있는 재료 설정, OpenSees 연결 함수, 단위·재료·요소·질량·접촉 검증을 별도 패키지로 정리했다. **실제 구조물에 입력하기 전 단계의 기준 패키지**이며, 모든 재료의 실험 보정 또는 구조물 안전 검증 완료를 의미하지 않는다. 최종 전체 재실행에서 선정 구현의14개 검증 그룹이 모두 통과했다. 코드 해시가 결과 기록과 일치함을 확인했다. 판정은 `results/verification_manifest.json`, 요구사항별 확인은 `results/completion_audit.json`에 기록했다.

원본 코드는 그대로 보존했다. 지반 연결 대상은 실제3D bbarBrick을 만드는 `ground/ground_modeling/ground_modeling.py`로 선정했다. 이름만 보고 `ground_modeling_3d.py`를 선택하지 않았다.

## 기존 진행 사항에서 수정할 점

- 기존 AW6014 보정 결과를6061-T6에 재사용하면 안 된다. 6061-T6 압출재 문헌값으로 새 기준을 만들었다.
- 기존 S355는 보정이 전혀 안 된 상태가 아니었다. 동일 출처 독립 시편2개에서 현재 환경의 range-NRMSE가 약2.98%,3.33%로 재현됐다. 일반 강재 전체·다축 파괴로 적용 범위를 넓히지는 않는다.
- RC의 실행 완료만으로 합격시키면 안 된다. 기존 방식은 적분점에 따라 반복이력이 변했다. 철근 위치의 콘크리트 중복을 제거하고, 힌지 길이를 명시하는 HingeRadau 방식으로 분리했다. 재료 상수를 바꿔 수렴 문제를 숨기지 않았다.
- RC 선정 모델은 섬유 분할·증분 비교, 제하 후 잔류변위, 축력비0/0.05/0.10/0.20 및3D 초기 축·양축 휨·비틀림 검사를 수행했다. 한 수렴 실패는 허용오차를 완화하지 않고 증분을 이분해 회복했다. 이 축력비 범위는 검증 예제 범위이지 모든 형상의 보증 범위가 아니다.
- PDMY02의 numerical c는 흙의 실제 점착력과 다르다. 달/화성 대표값은 지구중력에서 시험한 모사토 자료이며 실제 현장 보정값으로 표시하지 않는다.
- 지반 중력 재시도 때 하중을 중복 증가시킬 수 있던 경로를 수정하고, PDMY stage 전환 뒤 다시 평형을 확인했다.
- DP 점착력 변환, SI 단위 J2 소성화, 접촉 미끄럼·들뜸에서 실제 수치 문제가 드러났다. 이론식/독립해와 비교해 수정하거나 구현을 교체했으며 실패 증거도 research에 남겼다.
- 차폐층은 질량+수직 하중으로 취급한다. 느슨한 레골리스에 구조용 쉘 인장/휨 강성을 주지 않는다. 소결 구조재와 지반재·차폐재는 별개 record다.

## 선정 결과

구체적인19개 record 및 출처·가정·상수는 `configs/catalog.json`, 적용방법은 `README.md`에 있다.

- 강재: 일반 비교용 S355 명목 모델 + 기존 보정 Steel02를 용도별로 분리.
- 알루미늄:6061-T6 압출재,293K 탄성/항복 기준. 이후 경화·피로·용접 영향은 미보정.
- RC: 비구속 C30/SD400 명목 구성재 + 실제 배근을 입력하는 힌지 부재. 기초 solid는 철근비를 입력하는 초기 탄성 RC 기준 모델도 제공.
- CFRP: AS4/8552 UD 시험 평균값,0/90 적층 쉘과 ABD/ply 검토. 허용값·손상모델로 해석하지 않음.
- 지구: 건조 기준 사질토 PDMY02. 달:JSC-1A 밀도별 peak/residual. 화성:JEZ-1 peak/residual 및 강성 민감도.
- 구조용 레골리스: 동일2016 시험군의 소결 JSC-1A를 선택. 인장강도가 확인되지 않아 인장 파괴 판정은 보류.
- SSI: 작은 슬립·고정 법선의 무점착 Coulomb 접촉, 면적별 penalty와 방사 감쇠 환산. 실제 접촉 재료쌍과 기초 형상은 후속 입력.

## 검증 범위와 남은 일

`run_verification.py`가 선택 구현의 재료 패치, 금속 쉘 소성 이력, 강재 시편 재현, RC 힌지/3D/연속체, CFRP 막·굽힘, 지반 재료/중력, 질량 고유치, 접촉·하중 전달·감쇠 검사를 다시 실행한다. 결과는 개별 JSON/CSV와 manifest로 보관된다. 통과 여부를 실행 종료코드만으로 판단하지 않는다.

남은 일은 실제 구조물 코드 수령 후 **재료 배정과 형상 의존 입력 확정 및 통합 검증**이다. 부재/두께/배근, RC 힌지 길이/GJ, CFRP 적층방향, 차폐 두께, 기초 크기·접촉면적/재료쌍, 동적 경계와 입력운동을 결정해야 한다. 자중·내압 전달과 모드·SSI 응답을 순서대로 확인한다. 현장자료 없는 흙의 액상화, CFRP 박리, 소결재 인장파괴, 운석 관통을 이번 패키지가 검증한 것으로 사용하면 안 된다.
