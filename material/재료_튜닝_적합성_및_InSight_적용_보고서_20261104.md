# 재료 선정·튜닝·사용 적합성 및 InSight 코드 적용 보고서

작성일: 2026-11-04 (한국시간)  
검토 대상: 저장된 재료 패키지, 기존 검증 결과, 현재 실행 코드. 이번 작업은 새 현장 시험이나 전 재료 재보정이 아니다.

## 1. 핵심 판단

수정 전 `ground_modeling_insight_updated.py`는 튜닝 카탈로그를 읽지 않았다. 파일에 하드코딩된 화성 초기값을 사용했으며, `--insight-local` 동적 실행의 기본 옵션은 `elastic`이었다. 따라서 그때의 출력은 기존 튜닝 패키지의 비선형 화성 지반 응답이라고 설명할 수 없다.

이번 수정으로 화성 모델은 기존 `ground_hybrid` 카탈로그의 **InSight duricrust 대리재료 + JEZ-1 모사토 + 현무암 아날로그**를 직접 사용한다. 기본 동적 옵션은 `nonlinear`이며, 앞의 두 재료는 Drucker–Prager 마찰 소성, 기반암은 선형 탄성이다. 암반 파괴를 보정한 자료가 없으므로 암반까지 임의의 비선형 모델로 바꾸지 않았다. `--dynamic-material-model elastic`은 명시적인 비교용으로만 남겼다.

여기서 ‘튜닝’은 시편 실험 보정, 문헌 강도 정리, 구성식 변환, 단위 변환 및 수치 검증을 포함하는 기존 작업의 통칭이다. 모든 재료가 반복 실험곡선으로 보정되었다는 뜻은 아니다. 특히 화성 JEZ-1은 문헌 전단강도 기반이며 반복강성·감쇠·팽창은 현장 보정되지 않았다. 비선형 구성식이 활성화되어도 작은 지진 입력에서는 응답이 탄성 범위에 머무를 수 있다. 변형을 크게 보이게 하려고 강도나 입력 배율을 바꾸어서는 안 된다.

## 2. 현재 코드의 실제 적용 상태

| 실행 경로 | 현재 사용하는 재료 | 판정 |
|---|---|---|
| `ground_modeling_insight_updated.py --insight-local` | 카탈로그의 화성 DP 2종 + 탄성 현무암 | 이번에 연결, 기본 비선형 |
| 위 명령 + `--dynamic-material-model elastic` | 동일 물성의 선형 탄성 비교 모델 | 사용자가 명시한 경우만 |
| `ground_modeling.py --insight-local` | 위 동적 코드로 전달 | 동일한 화성 재료 경로 |
| `ground_modeling.py`의 일반 실행 | `ground_hybrid`의 별도 혼합 지반·기초 모델 | InSight 동적 코드와 모델·경계·형상 다름 |
| updated 파일의 Earth/Moon 실행 | 기존 파일 내부 재료 | 이번 화성 연결 변경의 대상 아님 |
| updated 파일의 상부 구조물 | 강재·RC·CFRP 등의 실제 구조물 미조립 | 재료 패키지 존재와 실제 구조물 배정은 별개 |

`get_body_config → MARS_CONFIG → MARS_SOIL_MATERIALS → register_opensees_soil_materials → ground_hybrid.materials.register` 순서로 카탈로그 값이 OpenSees에 등록된다. DP 재료에 PDMY 전용 stage 명령을 적용하지 않으며, DP는 중력 재하부터 비선형으로 계산한다. 로그의 PDMY stage-control 목록이 비어 있어도 DP 비선형이 꺼졌다는 의미가 아니다. 실제 구성법칙은 `Active constitutive laws`와 `insight_materials_used.json`에서 확인한다.

### 화성 재료와 층 배정

| 깊이/역할 | 카탈로그 ID | 구성모델 | E [MPa] | ν | ρ [kg/m³] | φ [°] | c [kPa] |
|---|---|---|---:|---:|---:|---:|---:|
| 0–0.2 m 표층 | mars_insight_duricrust_proxy | DruckerPrager | 11.48 | 0.28 | 1200 | 30.0 | 5.8 |
| 0.2–8 m 레골리스 | mars_jez1_peak | DruckerPrager | 30 | 0.30 | 1840 | 40.6 | 3.1 |
| 8 m 아래 기반암 | basalt_elastic_analogue | ElasticIsotropic | 40000 | 0.30 | 2900 | — | — |

층 두께와 배정은 **해석 시나리오 가정**이다. InSight 표층 자료, JEZ-1 실험 모사토, 현무암 아날로그를 조합한 것으로 한 장소에서 확인한 지층 주상도가 아니다. HiRISE DEM도 지하 재료와 층 두께를 직접 제공하지 않는다.

duricrust의 c는 φ=30°, ρ=1200 조건에서 추정된 값이다. E=11.48 MPa와 ν=0.28은 얕은 지반의 40–80 Hz 파동 추정 물성을 표층에 전용한 대리값이며, 0.05–2 Hz 지진 입력의 정적/동적 강성으로 독립 검증된 값은 아니다. JEZ-1의 E=30 MPa와 ν=0.30은 가정값이다. 두 재료 모두 최소한 강성 0.5/1/2배 민감도 검토가 필요하다. DP의 삼축 압축 기준 변환이 직접전단 시험의 모든 응력 경로를 정확히 일치시키지는 않는다.

DP는 현재 일정 탄성강성과 마찰 완전소성을 사용한다. PDMY02의 압력 의존 강성, 반복 수축·팽창 또는 액상화 모델과 같지 않다. `peak`와 `residual`은 별도 경계 재료이며, 하나의 모델에서 자동으로 연화 전환하지 않는다.

### 계산 설정 변경

0.2 m 표층을 1 km/41격자에 그대로 넣으면 수평/수직 요소 비가 과도해진다. 기본 InSight 확인 영역은 **100 × 100 m, 수평 17 × 17 절점**으로 조정했다. 이는 메시·영역 독립성을 확보한 최종 모델 크기가 아니다. 1 km 모델이 필요하면 얇은 표층 해상도와 계산량을 함께 검토해야 한다. 강성·강도를 바꾸어 수렴을 맞추지는 않았다.

중력은 카탈로그의 기존 비선형 하중 연속 알고리즘을 재사용한다. 알고리즘 재시도와 증분 축소로 하중계수 1까지 진행하며, 실패하면 종료한다. 이전처럼 실패 후 전체 하중 단계를 다시 더하지 않는다. 힘 잔차 기반 수렴, 최종 힘 평형 검사와 하중계수 진행 로그를 사용한다. 재료 종류·출처 카탈로그 해시·층 경계는 `insight_materials_used.json`으로 남긴다. 이 파일의 생성만으로 전체 해석 성공을 판정하지 않는다.

### 과거 후보 중 최종 선정 패키지와 구분할 항목

황콘크리트·레골리스 지오폴리머·일반 콘크리트 쉘은 과거 탄성 비교 코드가 존재하지만, 최종 19개 record 카탈로그의 확정 실험보정 재료로 포함되어 있지 않다. 배합·양생·온도·인장/취성파괴 자료가 필요한 후보로 둔다. AW6014 T4/T6는 일부 단조 인장 보정 및 식별성 검토 이력이 있으나 6061-T6와 다른 합금이다. UCSD Grade60 철근 보정도 SD400 prototype과 구분한다. PM4Sand/PM4Silt/PIMY 및 말뚝 p-y/t-z/q-z 등 과거 구성모델 후보를 현재 InSight DP 코드의 실제 재료로 열거하지 않는다.

## 4. 검증 근거와 결과 해석

기존 release의 저장 manifest는 14개 검증 그룹의 성공 종료를 기록한다. 재료 패치·금속 쉘·강재 시편·RC 단면/힌지/3D/연속체·적층·질량·지반·접촉 검사를 묶은 결과다. 이번에 14개 전체를 새로 실행한 결과로 표시하지 않는다.

별도 hybrid 저장 결과는 재료 36조건(33개 DP 구속압 조건과 3개 PDMY 반복전단)의 통과를 기록한다. 이는 구성식/이론 강도/평형을 확인하는 **수치 검증**이며 독립적인 실제 화성 현장 검증이 아니다. 기존 보고의 달 큰 조립 모델 수렴, 메시·영역 독립성, 큰 미끄러짐 검증 미완료 상태도 유지된다.

이번 코드 변경의 새 검증은 아래 갱신 항목에 기록한다. 전체 약 3000초 기록과 기본 격자의 완주를 짧은 smoke test로 대신했다고 표현하지 않는다. 비선형 모델 활성 여부는 카탈로그 값·등록된 구성법칙·단위요소 항복 시험으로 확인하고, 실제 지진에서 소성 발생 여부는 별도 응력·소성변형률/소성일 계측으로 판정해야 한다. 현재 변위 애니메이션만으로는 소성 발생을 증명할 수 없다.

지표 관측 가속도를 기반 입력으로 쓰는 고정 바닥/자유 측면의 기존 실험 경계는 유지한다. 재료 연결 수정이 경계 반사·입력 위치·감쇠·DEM 위치 불확실성을 해결하지는 않는다. 0.05–2 Hz 필터와 10 Hz 출력의 공간/시간 해상도, 기초·실제 구조물 질량, 감쇠 보정은 최종 해석 목적에 맞춰 별도로 확인해야 한다.

### 이번 변경의 실제 확인 결과

- InSight의 실제 재료 등록 함수를 통과한 DP 2종 × 구속압 1/15/60 kPa의 삼축 항복 6조건: 전부 통과. 해석식 대비 최대 항복 상대오차 약 3.80×10⁻¹⁵. 강도를 초과하는 변형 경로에서 구성식이 소성 항복을 구현하는지 확인한 수치 시험이다.
- 실제 HiRISE DEM + 새 S1222a 입력 + 100 × 100 m, 17 × 17 수평 절점: 중력 하중계수 1 및 동적 10단계(1초) 완료. 4,624절점, 3,840요소. 기본 격자는 이 확인 조건에 맞췄다.
