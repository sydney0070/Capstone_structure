시편과 시험 범위

3D 시편은 모두 1×1×1m 정육면체입니다. 이는 층 두께나 기존 90×90m 지반을 축소한 모형이 아니라 재료 법칙을 확인하는 단일 요소 시험입니다. 탄성·DP에는 bbarBrick, PDMY02 반복 전단에는 SSPbrick을 사용했습니다. 모든 연속체 재료의 밀도는 bbarBrick 1m³의 고유치 기반 질량으로 별도 확인했습니다.

탄성·DP는 구속압 5/50kPa에서 압축–제하를 수행하고 E, DP 삼축압축 항복식, 측압 유지, 균일 응력, 축력 평형을 확인했습니다. PDMY02는 수직 유효응력 5/80kPa에서 ±0.001%부터 ±0.5%까지 반복 전단했습니다. 수평 변형은 구속하고 체적 변화는 허용하므로 평균압은 수직압과 다릅니다. 간극수·액상화 시험은 아닙니다.

단축 후보는 두 노드 zeroLength 배치를 정의하고 동일 재료를 testUniaxialMaterial/setStrain으로 누적·커밋해 힘–상대변위를 기록했습니다. 전역 평형 해석이나 링 분담면적 환산을 수행한 결과는 아닙니다. Qz는 수직, Py/Tz는 수평 방향입니다.

경화층 E·ν는 천부 유효 파속 자료를 이전한 값이고 ρ1025는 추정 범위의 중간 선택값입니다. c5.8kPa는 원 논문에서 φ30°, ρ1200을 가정한 추정값입니다. 국부 자갈층 E는 모래 기질의 대용값이며, 표면·자갈·분출물 DP의 c0/φ30–35°는 시험용 가정입니다. 암반·퇴적층의 소성 강도는 만들지 않았습니다.

출처값과 입력값의 구분

  • Brinkman 표4에서 E11.48MPa와 ν.28을 선택해 G4.484MPa, K8.697MPa를 일관되게 계산했습니다. 표의 독립적인 최빈 G/K 값 전체를 동시에 조합한 것이 아닙니다.
  • MGS-1/MGS-1S의 E28.4MPa·ν.22·ρ1300과 기존 c/φ를 보존했습니다. 모사토 저압 직접전단값을 이 밀도·강성에 이전한 초기값이며 고압 강도 보정은 아닙니다.
  • PDMY02 공식 기준 5개는 지구 모래 표입니다. G/K는 표의 80kPa 값에서 (101/80)^0.5로 환산해 refPress101kPa에 맞췄습니다. 표의 서로 다른 기준압 표기를 처리한 선택입니다.
  • 화성 PDMY02 4개는 각 DP의 ρ/G/K/φ를 사용하고, refPress5kPa를 임의 기준으로 선택했습니다. 수축·팽창·임계상태·e·압력지수는 Dr50 기준의 미보정 이전값입니다. 물리적 Dr50을 뜻하지 않습니다. numerical_c300Pa는 DP의 c280Pa와 같은 보정값이 아닙니다.
  • Qz/Py/Tz 힘과 변위는 지구 얕은기초 문헌 예제입니다. QzSimple1은 QzSimple2와 같은 입력을 쓴 법칙 비교입니다. ElasticPPGap/Hysteretic은 문헌 E·c·φ로 규모를 정한 합성 기능 비교이며 실제 경화층·암반 절리의 곡선이 아닙니다.

현재 사용 판단

첫 탄성·DP 비교군은 층별 초기 강성·정적 항복 민감도 비교에 사용할 초안입니다. PDMY02는 반복 곡선·압력 의존 강성의 추가 보정이 필요합니다. 특히 화성 모래·자갈 초안은 자동 증분 분할이 필요했으므로 전체 지반에 바로 적용할 재료로 선정하지 않았습니다. 단축 스프링은 링 기초의 실제 하중–침하·분담면적·들림 조건으로 보정해야 합니다. Py/Tz의 법선력 연계는 포함하지 않았습니다.

천부 수십 cm의 국부 층서와 3/13m 참조 경계는 서로 다른 근거입니다. 저속도 퇴적층의 파속은 Hobiger 표2의 사전모델을 사용했으며 실제 역산 곡선의 특정 깊이 물성을 읽은 것으로 간주하지 않습니다.
