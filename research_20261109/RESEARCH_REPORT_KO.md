## 3. 재료 단독 검증

### 3.1. 구성식·단면 15개 검사

`material_benchmarks.py` 결과: 15개 모두 사전에 명시한 수치 검사 통과.

- JEZ-1 및 달 JSC-1A DP: 구속압 1/15/60kPa에서 삼축 압축 항복값을 독립 Mohr–Coulomb 해석식과 비교.
- duricrust proxy DP: 1/15kPa 비교.

- Concrete02 및 SD400: 반복 이력의 부호·유한성 검사.

구속압 1kPa 검사 통과는 **구성식 계산/변환 검증**이다. 시험 자료의 낮은 구속압 외삽이 실험적으로 검증됐다는 뜻은 아니다. 시편 holdout 통과도 SHS 부재·용접·국부좌굴을 검증하지 않는다. 콘크리트/철근 반복 부호 검사는 실험 일치의 합격 기준이 아니다.

DP의 기존 점착력 변환은 임의로 문서 식으로 바꾸지 않았다. 저장소의 invariant 유도와 실제 삼축 benchmark가 일치하는지를 먼저 확인했다. 구현 식과 문서의 정규화 차이는 기존 `dp_mapping_note.md`에 보존되어 있다.

## 7. 모든 적분점과 소성·일 진단

기존 첫 적분점 초기/최종 snapshot에 더해, `--ground-history`로 평탄 직교 지반의 모든 8개 GP와 성공한 동적 세분 단계마다 관측하도록 했다. 현재 기본 지반은 1176개 요소, **9408개 적분점**이다.

- 선형 탄성 compliance를 사용해 `εp = ε − C⁻¹σ`를 계산하고, 전체 소성변형과 동적 시작 상태 대비 증분을 분리한다.

분해 잔차가 작다는 것은 이 계산의 회계적 일관성이다. 전체 구조+접촉+감쇠+입력의 독립 에너지 보존 검증이 아니다. 현재 일 적분은 직교 직육면체 요소에 한정되므로 실제 요철의 일반 Jacobian 적분에는 이 도구를 그대로 사용하지 않는다.

## 9. 화성·달 연결부 초안

첨부 자료에서 기초 형식을 참고해 **화성 전면기초**, **달 환형기초**를 작성했다. 문헌의 0.20m 또는 17m/30kPa 사례 수치는 현재 돔의 검증 치수·하중으로 전용하지 않았다. 같은 강재 돔 형상을 축척해 연결부와 SSI를 비교하는 코드다. 문헌의 지오폴리머 돔 자체를 재현하지 않는다.

### 9.1. 화성

원형 전면 판(ShellMITC4) → 면적 가중 접촉 → 비선형 화성 토층. 돔과 기초는 상대 회전 고정이 기본이다. 모든 지원 절점의 질량·자중·분담면적을 계산하고 별도의 가상 지반 스프링을 중복 추가하지 않는다.

### 9.2. 달

환형 판(ShellMITC4) → 면적 가중 접촉 → 비선형 JSC-1A 아날로그. 돔 상대 회전 고정/힌지를 비교할 수 있다. 판 재료는 명시적인 탄성 예시 물성이며 달 현장 보정 재료로 표시하지 않는다. 크레이터 공극·급경사·굴착은 구현하지 않았다.

### 9.3. 공통 연결부

- `fixed`: 돔과 기초 사이의 상대 변위·회전 일치. 지반에 대한 전역 고정이 아니다.
- `hinged`: 병진만 연결, 돔 회전은 독립.
- `spring`: 입력된 회전 강성으로 세 축 회전을 연결. 근거 없는 기본 회전 강성을 자동 부여하지 않는다.
- 선택적 인장 연결부: 강성·항복 인장력을 함께 명시해야 하며 압축은 전달하지 않는다. 앵커 매입/부착/인발 저항을 보정한 모델은 아니다. 압력 폐합 없이 이를 가압 안전 설계로 해석하면 안 된다.

## 16. 달 초기응력 경로의 추가 분리 실험과 API 확인

달 40m 환형기초는 수직 간격4m·정적10증분으로 줄여도 처음 정적 호출에서 220초 내 완료되지 않았다. 소형 사례만으로 확대 모델을 검증 완료로 볼 수 없다.

추가 진단에서 **OpenSees3.4의 DP에 updateMaterialStage 호출이 적용되지 않는 것**을 확인했다. 로그의 “no effect” 경고를 확인한 뒤 해당 경로를 탄성 seating 성공으로 해석한 임시 표기를 취소했다. `moon_seating_small`은 실제로는 두 패턴의 비선형 재하 비교이며, 요청한 탄성 상태 전환의 검증 자료가 아니다. 원래 로그/잘못된 해석 사본도 거부 기록으로 남겼다. 기존 기본 해석은 DP에 이 wrapper를 호출하지 않으므로 이 문제로 탄성 상태에 놓인 것은 아니다.

올바른 `materialState` 요소 parameter 경로는 독립 신선한 단일요소의 두 전단 시험에서 검증했다. stage0의 최대 전단응력57,692.31Pa는 독립 탄성식 G×0.005와 일치했고, stage2 DP는8,268.83Pa였다. 두 경로 모두 평형·유한성 검사를 통과했다. 항복면 밖의 큰 탄성 상태에서 갑자기 전환한 초기 시험은 재평형에 실패하여 별도의 거부 기록으로 보존했다.

수정한 `dp_seating_probe.py`는 별도 초기화 진단이다. 요소 parameter로 DP를 stage0에서 자중0.1%까지 탄성 seating한 뒤 원래 E/G/K·강도와 stage2 DP로 나머지99.9%를 재하한다. 압력에 따른 탄성계수 갱신 stage1은 사용하지 않는다. 일반 기본 실행과 카탈로그 계수는 바꾸지 않았다. 이 실험은 초기응력 경로 민감도이며 실제 굴착·설치 이력의 검증 모델이 아니다. 최종 상태는 manifest의 `moon_seating_verified_small` 및 후속 항목으로 확인한다.

### 16.1. 수정 API 적용 후 결과

정확한 요소 materialState 경로를 사용한 소형 달 사례도 완료됐고 최대침하 변화는 기준 대비 약 -2.54×10^-11%였다. 40m 달 사례는 작은 탄성 seating 단계까지 완료했으나, 이어지는 DP 비선형 재하에서 forceBeamColumn 업데이트 실패가 나타나 175초 제한으로 중단됐다. **초기 seating만으로 대형 달 모델의 문제를 해결하지 못했다.** 해당 실험은 기본값으로 채택하지 않았다. 작은 시작 증분, 검증된 재료 상태 전환, 판 면적을 해상한 모델만으로 모든 규모의 불수렴이 해소된다고 주장하지 않는다.
