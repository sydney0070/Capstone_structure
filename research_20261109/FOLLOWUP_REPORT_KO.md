## 1. 현재 결론

지반의 기본 비선형 Drucker–Prager(DP) 모델을 유지하면서, 실행 관리 결함, 접촉 경계가 달라지는 메시 비교, 지형 요소의 적분점 이력 제한, 동적 세부 시간 단계의 최대값 누락을 수정했다. 카탈로그의 E·φ·c·ψ, 강재·콘크리트 계수는 수렴을 위해 변경하지 않았다. 탄성 지반과 병진 연결 사례는 원인 분리용 진단으로만 실행했다.

**40 m 달 모델과 기존 12점 링 모델의 모든 수렴 문제가 해결된 것은 아니다.** 소형 달 모델의 최대·평균침하는 메시 변화에 안정적이지만, 차등침하와 소성 지표는 아직 안정적이지 않다. 완료되지 않은 세 번째 메시 수준까지 합격으로 취급하지 않는 판정 코드를 추가했다. 최종 소스는 연구용 모델로 계속 발전시킬 수 있으나, 현재 결과만으로 설계 안전성·지지력·최적 기초를 판단할 수 없다.

## 3. 위치와 지반 모델

화성 기준은 계속 **ELYSE StationXML의 위도 4.502384°N, 경도 135.623447°E**이다. 결합 모델의 기본 지표면은 해당 위치의 DEM 높이를 기준으로 만든 수평 기준면이다. 실제 지형이나 착륙지의 측정 층서를 복원한 것으로 표현하지 않는다. DEM와 StationXML의 높이 차이도 이전과 같이 보존한다.

이번에는 실제 ELYSE DEM 굴곡에 대해 전체 적분점 이력을 계산하는 지반 단독 실행도 완료했다. 1,536개 요소, 12,288개 적분점, 자중 20단계 이력을 저장했다. 이 자중 조건의 최대 계산 소성변형률은 약 5.3×10⁻¹⁹로 수치 오차 수준이었다. **비선형 법칙을 사용한 실행이지만 이 조건에서 소성 활성화를 입증한 사례는 아니다.**

경사지형 이력에는 적분점마다 다른 detJ를 적용한다. 뒤틀린 시험 요소의 체적·변형 에너지 적분과 OpenSees의 실제 변형률 응답 순서를 확인했다. 일의 분해 잔차가 작은 것은 계산상 장부가 맞는다는 뜻이며, 구조물·접촉·입력·경계까지 포함한 전체 에너지 보존을 입증하지 않는다.

실제 DEM 위에 기초를 설치하려면 정지 작업, 굴착·다짐, 기초의 실제 지지면과 시공 이력을 정해야 한다. 그 자료 없이 지형을 평평하게 만든 일을 시공 모델링으로 간주하지 않았다. 달은 선정한 착륙지·분화구·관측 지진 입력이 없는 합성 기준 지반이다.

## 4. 동일 접촉 경계의 비선형 메시 비교

새 `conforming_mesh.py`는 정사각형 중심부, 다각형 원주 구간, 정사각형 외곽을 연결한다. 원형 기초의 실제 표현은 다각형이다. `--plan-refinement`는 다각형의 기존 직선 경계를 이동시키지 않고 평면 요소를 분할하고, `--vertical-subdivisions`는 각 기존 깊이 구간을 분할한다. `--sectors`를 바꾸면 원의 근사 형상이 달라지므로 별도 형상 민감도로 취급해야 한다.

지반 요소의 양의 Jacobian, 형상비, 외곽 면적, 전체 체적, 중량 합, 노드·요소 태그 충돌, 기존 재료 검사를 유지했다. 형상비 검사를 통과하지 않은 큰 모델의 거친 격자는 실제로 거부했다. 제한을 완화해서 실행시키지 않았다.

native 표본 추적 두 번에서 정체 시점의 UMFPACK 수치 분해 및 SuperLU factorization 호출을 확인했다. 이는 재료 내부 무한루프나 구조 파괴를 확정한 증거가 아니다. 관찰 결과는 **상재 하중을 받는 비선형 지반과 기초의 현재 접선 결합, 선형 해법·계산 자원의 영향**을 추가로 조사해야 한다는 쪽으로 문제를 좁힌다.

사용한 native 엔진은 `ops.version()` 기준 3.4.0이다. 파이썬 패키지 표시 버전만으로 새 엔진이라고 간주하지 않는다. 해당 버전의 UMFPACK 구현은 소스에서 확인한 고정 제어 설정을 사용한다. 문서에 보이는 모든 최신 옵션을 이 바이너리가 지원한다고 가정해 전달하지 않았다. 메모리 오류(-1)는 하중 평형 실패와 다른 오류다. 공식 [3.4.0 UMFPACK 연결 소스](https://github.com/OpenSees/OpenSees/blob/v3.4.0/SRC/system_of_eqn/linearSOE/umfGEN/UmfpackGenLinSolver.cpp)와 [UMFPACK 상태 정의](https://github.com/DrTimothyAldenDavis/SuiteSparse/blob/dev/UMFPACK/Include/umfpack.h)를 참고했다.

과거 잔존 worker와 라이브러리의 다중 스레드 실행도 확인했다. 이후 감독 실행은 작업 프로세스에 기본 1스레드를 설정하고 설정값을 기록한다. 필요하면 `CAPSTONE_SOLVER_THREADS`로 명시한다. 일부 검증은 동시에 실행된 구간이 있어, 보고서의 개별 실행 시간을 순수 성능 비교로 사용하지 않는다. 스레드 설정만으로 대형 달 문제를 해결했다고 주장하지 않는다. [OpenBLAS 런타임 변수 문서](https://www.openmathlib.org/OpenBLAS/docs/runtime_variables/)도 확인했다.

마지막으로 방정식 순서만 AMD로 바꾼 분리 진단도 실행했다. 재료·하중·허용오차를 바꾸지 않았지만 첫 단계에서 제한 시간 내 완료되지 않았다. 이 옵션을 해결된 기본 해법으로 추가하지 않고 연구 스크립트에만 남겼다. [공식 AMD numberer 문서](https://opensees.berkeley.edu/wiki/index.php/AMD_Numberer)를 참고했다.

## 6. 동적 최대값 누락 수정의 실제 검증

기존 40 m 화성 모델의 축소 시간 창, 가상 PGA 0.5 m/s² 조건에서 바깥 출력 0.05초마다 실제로 0.025초 적분을 두 번 수행했다. 바깥 출력은 40개, 실제 성공한 커밋은 80개였다. 별도로 0.025초를 직접 지정한 실행의 전체 커밋 응답 배열과 차이가 0이었다.

| 목표 구간 지표 | 바깥 출력만 집계 | 모든 커밋 집계 |
|---|---:|---:|
| 링 최대 증분변위 [mm] | 2.121257 | 2.122935 |
| 돔 최대 증분변위 [mm] | 2.216817 | 2.218096 |

해당 누락은 링 약 0.0790%, 돔 약 0.0577%였다. 이 사례에서 작았다는 사실로 다른 강한 비선형 입력에서도 작다고 가정하지 않는다. 수정 후 재료·접촉 극값과 지반 이력도 커밋마다 관찰한다. `committed_response.csv`와 `dynamic_checkpoint.json`을 추가했고 기존 바깥 출력 CSV는 유지했다.

지진 입력은 여전히 ELYSE 관측 파형을 이용한 연구 시나리오다. 관측 지표면 가속도를 기저 입력으로 사용하는 가정, 역산된 기저 운동 부재, 근사 흡수 경계, 제한된 시간 창은 남아 있다. 가상 PGA 증폭을 설계 지진으로 표현하지 않는다.

## 7. 재료 측면에서 추가로 확인한 한계

달의 세분화한 4 m 모델에서 JSC-1A 계열로 계산한 모든 적분점의 평균 압축응력이 15 kPa보다 작았다. 층별 범위는 대략 0.077–0.660, 0.669–1.765, 2.261–5.202 kPa였다. 이는 참조 삼축시험의 15–60 kPa 구속압 범위와 다른 낮은 응력 영역임을 경고하는 자료다. **평균응력은 삼축 구속압 σ₃와 동일하지 않으므로 실험 범위 충족 여부를 엄밀히 인증하는 지표로 사용하지 않는다.**

따라서 현재 필요한 자료의 우선순위는 다음과 같다.

1. 지반: 낮은 구속압의 체적변형·반복전단 자료, 밀도별 강성·감쇠, 현장 층서·Vs·단위중량. 현재 ψ=0과 일정 탄성계수의 물리 보정은 여전히 불충분하다.
2. 지반 국부 소성: 현상에 맞는 경화·연화 및 정규화 방법을 선정할 실험 자료. 메시를 잘게 만드는 것만으로 국부 소성의 객관성을 확보했다고 간주하지 않는다.
3. RC·강재: 실제 링 단면의 전단·부착·균열/힌지 길이 자료, 실제 SHS의 반복 이력·국부 좌굴·기하 결함 자료. 기존 수치 단면·쿠폰 검증을 전체 부재 검증으로 확대 해석하지 않는다.
4. 기초·연결부: 화성/달에서 적용할 재료와 시공 방법, 회전 강성, 앵커 인발, 미끄럼·들림 실험. 현 30 GPa 균질 탄성 판과 선택형 앵커는 보정된 행성 재료·시공 시스템이 아니다.

이 자료를 확보한 것처럼 계수를 맞추거나 안전 여부를 출력하지 않았다. 입력 데이터가 필요한 물리 보정과 이번에 실제 완료한 코드 보완을 구분한다.

## 8. 코드의 계속 사용 가능성

계속 사용할 기반은 재료 범위 검사, 지반 요소·질량·중량 구성, 좌표 기준 관리, 접촉 조립, 명시적 연결부, 이력·실행 상태·검증 도구다. 새 고정 경계 격자는 비선형 메시 연구에 사용할 수 있다. 기본 Cartesian 경로를 무조건 교체하지 않고 명시적으로 선택하도록 했다.

기존 12점 RC 링의 점 접촉은 실제 기초 폭을 면으로 전달하지 않는다. 접촉 penalty 면적을 지정한 것만으로 면 지지력이 모델링된 것은 아니다. 이 경로를 유한 폭 기초의 최종 검증 코드로 계속 사용하지 않는 편이 타당하다. 판 기초 초안은 이 한계를 줄이는 별도 물리 모델이지만 RC 보 링과 같은 구조나 질량이 아니므로 결과를 직접 성능 개선으로 비교하면 안 된다.

실험 옵션 `--initial-tangent-first`, `--initial-tangent-seed`, `--symmetric-gravity`는 기본 해법으로 채택하지 않았다. 초기 접선 반복도 비선형 응력 갱신과 동일한 평형 잔차 검사를 수행한다. 대칭 옵션은 정적 자중 연구만을 위한 것이고, 구속 반력이 유의하면 결과를 거부한다. 정적 보조 구속을 실제 앵커나 지진 해석 지지로 옮겨 쓰면 안 된다.
