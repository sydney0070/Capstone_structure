# 논문·외부 참고자료 중앙 보관함

원문을 찾을 때는 [검색 가능한 전체 목록](index.html)을 연다. 문헌 조사를 할 때 확인한 논문·보고서는 이 폴더의 주제별 분류에 저장하고, 기존 자료는 중복 다운로드 대신 기존 항목에 조사 이력을 연결한다.

| 분류 | 저장 내용 |
|---|---|
| 01_ground | 화성·달 지반, 층서, 조성 및 레골리스 물성 논문 |
| 02_material_properties | 구조재 물성과 시험자료 |
| 03_prior_structures | 구조물 선행연구 |
| 04_SSI_and_numerics | 지반–구조물 상호작용, 얕은기초 및 수치해석 연구 |
| 05_official_model_docs | OpenSees 공식 매뉴얼과 구현 원문 |
| 06_original_data | 외부 시험 원자료 |
| 07_observations | 관측·위치 원자료 |

PDF는 파일 형식과 파싱을 확인하고, 출처 URL·참고 절·확보 상태 및 SHA-256을 목록에 기록한다. 원문이 없으면 서지·원 출처 링크를 보관하고 원문 미확보 목록에 남긴다. 초록이나 링크를 원문 PDF로 분류하지 않는다.

이번 2026-11-19 조사 자료는 `_catalog/research_20261119_crosswalk.json`에서 조사 ID와 중앙 보관 ID를 연결했다. 논문을 해석해 작성한 내부 보고서는 [문헌 조사 보고서](../../material/literature_review_20261119/review_KO.md)에 보관한다.
