# 2026-11-09 오류 수정·InSight 기준 위치 연결

기존 1107 파일을 직접 수정했다. 파일명은 유지하며 summary.json의 revision 필드와 코드 해시로 이번 개정을 구분한다. 과거 보고서·기존 결과·재료 카탈로그 계수는 덮어쓰지 않았다.

## 수정한 오류

- 재료 감사: 중첩 params 수치의 재귀 비교, params 키 누락 및 알려지지 않은 law 거부, 병합 과정에서 덮이기 전 모든 record의 출처 참조 검사.
- 입력 이력: 선행 구간이 기록 시작점을 넘으면 기본 거부. --allow-short-warmup으로 명시 허용할 때만 축소하고 requested/effective/truncated 상태를 보존. duration과 시작 시각의 요청값·실효값도 기록.
- 비유한 응답: 매 외부 출력 단계 원시 변위·꼭대기 가속도·강재/RC 섬유 응답 및 접촉 힘·물리/보조 절점 변위를 집계 전에 검사. NaN/Inf를 검출하면 실패 처리. 적응 세분 내부의 모든 시간 극값을 저장하는 변경은 아니다.
- 입력 PGA가 0인 경우 target-pga 정규화 거부.
- 재현성: 해시 대상에 공용 지반·접촉·재료 모듈을 확대하고 런타임 패키지 버전을 저장. requirements_20261109.txt는 검증 환경에서 관측한 버전 기록이다. Git 커밋·원격 업로드는 하지 않았다. 저장소의 untracked 상태 자체는 남아 있으며 별도 소스 snapshot으로 이번 검증본을 보존한다.

## 지반 위치와 비선형성

수정 전 통합 1107 모델은 특정 화성 좌표가 없는 합성 평면이었다. 이전 독립 DEM 코드의 영상 중앙 위치와도 구별된다. 위치 검사 기능만 존재했고 통합 해석 지형에는 연결되지 않았다.

수정 후 기본 --site insight:

- 원점: StationXML의 ELYSE, 북위 4.502384°, 동경 135.623447°. 인사이트 착륙지 주변의 지진 관측소 메타데이터 좌표를 기준으로 한다. 착륙체와 실제 배치된 SEIS 사이의 미터 단위 측량 좌표를 새로 확정한 것은 아니다.
- 축: East/North/Up, 수평 영역 기본 60m × 60m.
- DEM: DTEEC_037262_1845_036761_1845_U01.IMG에서 해당 관측소 중심 패치를 실제 읽고 유효값 확인. 원본 DEM과 StationXML SHA-256 보존. DEM 누락/범위 이탈 시 다른 위치로 대체하지 않고 실패.
- 모델 z=0의 표고 기준: DEM 관측소 중심값 약 -2616.87846m. StationXML -2613.4m와 약 -3.47846m 차이는 그대로 기록하며 강제로 보정하지 않음.
- 실제 지형 샘플과 계산 지표를 site_dem_samples.csv에 함께 저장. summary.json/site에 위경도, 픽셀 좌표, 표고 범위, 평탄화 차이와 가정을 저장.
- 지진자료: 기존 S1222a_ACC.mseed 유지. 기본 InSight 모드에서 ELYSE 성분인지 확인. 지표 관측 자료를 기반 입력으로 사용하는 모델 한계는 남음.

중요: 이번 위치 연결은 **인사이트 관측소를 원점으로 한 평탄화 지반 모델**이다. DEM 실제 요철을 유한요소 표면에 적용하거나 굴착·성토 시공을 구현한 것이 아니다. 수평 링과 돔의 형상을 유지하고, 지형 변경으로 생길 접촉 간격이나 시공 응력 경로를 임의로 만들지 않았다. 60m 패치 DEM 표고 범위는 약 -2617.252∼-2615.692m로 약 1.56m의 차이가 있으므로 실제 지형 효과까지 무시할 수 있다는 검증은 아니다.

기본 --elastic-ground=false 유지. duricrust proxy와 JEZ-1 지반은 DruckerPrager 비선형, 하부 basalt analogue만 ElasticIsotropic이다. 결과에 active law를 저장하고 비선형 기본 실행에서 DP 지반이 없으면 거부한다. --elastic-ground는 명시적 진단 비교 옵션으로만 남겼다.

0.2m duricrust proxy / 8m까지 JEZ-1 / 하부 basalt의 기존 층과 계수는 유지했다. 위치를 맞춘 것과 ELYSE 현장 지층·재료를 실측 보정한 것은 다르다. DEM으로 지층·강도·감쇠를 얻었다고 주장하지 않는다. 비선형 메시 독립성 미확보도 해결됐다고 표시하지 않는다.

## 기초 후보 추천 — 추가 구현 없음

현재 통합 실행의 기초는 RC 링이다. ground_hybrid/interface.py에는 일반 raft용 보조 코드가 이미 있으나, 통합 돔에 연결하여 검증된 대안 기초라는 뜻은 아니다.

| 추천 순서 | 후보 | 비교 가치 | 주의점 |
|---|---|---|---|
| 비교 기준 개선 | 유한 폭 환형 판기초 | 현재 링과 가장 직접 비교; 폭에 따른 접촉압·들림·차등침하 | 중심선 beam/contact를 면 접촉으로 바꿔야 함 |
| 1 | 원형 전면 매트기초 | 전면 면적의 하중 분산·침하·회전을 링과 비교; 바닥 구조 검토와 연결 가능 | 재료량·휨/전단·접촉 들림 검증 필요; 판이 있다는 것만으로 압력 폐합이 완성되지는 않음 |
| 2 | 돔 지점별 독립기초 + 연결보 | 현재 12개 돔 지점과 대응; 재료 절감 가능성과 차등침하·국부 지반 소성 비교 | 연결보의 수평 추력 전달·기초 간 상호작용·국부 지지력 중요 |
| 3 | 방사형 줄기초 + 외곽 링의 격자기초 | 전면 매트와 독립기초 사이의 대안; 반력 재분배와 재료량 비교 | 교차부 강성·비틀림·접촉압 집중과 시공성 검토 필요 |

말뚝/마이크로파일·나사말뚝은 후순위다. 지지층 깊이·관입/천공 가능성·인발 및 주면저항 자료가 부족해 현 단계에서는 얕은기초 후보보다 추가 가정이 많다. 실제 현장 최적안 판정이 아니라, 현재 돔과 SSI 모델에서 비교할 연구 후보의 추천 순서다.

비교 시 돔 하중과 입력·지반·평가 구간을 통일하고, 같은 질량 비교와 같은 사용성 요구를 만족하는 질량 비교를 구분한다. 총침하·차등침하·회전·잔류변형·들림/미끄럼·접촉압·부재력·소성영역·시공/반입 질량을 함께 비교한다.
