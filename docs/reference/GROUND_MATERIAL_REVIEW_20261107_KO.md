# 지반·재료 코드의 구조물 해석 적합성 검토 및 수정 보고서

**버전 기준일: 2026-11-07 / 검증·보고 정리: 2026-11-08.** 사용자 요청 당시 날짜를 새 파일명에 유지했다. 기존 파일과 최종 material_release_20261101의 계수는 변경하지 않았다. GitHub 업로드는 이번 작업에 포함하지 않는다.

## 1. 결론과 적용 범위

현재 코드는 구조물–기초–지반의 **연결과 가정 조건의 응답 비교를 위한 연구 모델**이다. 실측 화성 현장의 정확한 최대 응답, 실제 지지력/파괴 또는 최소 안전 질량을 확정하는 모델은 아니다. 이번 개정은 데이터 입력·반력 보존·시간 이력·평형·관측량·실패 관리의 수치 문제를 수정했다. 재료 상수를 임의로 키워 계산이 끝나게 하거나 문헌 기준값을 현장 실험 보정값으로 바꾸지 않았다.

특히 **비선형 지반의 세분 격자 정적 해석 미완료**를 발견했다. 같은 세분 격자의 탄성 지반은 완료했으므로 비선형 구성식/초기응력 경로/조립체의 수치 상호작용에 대한 추가 진단이 필요하다. 이것만으로 DP 자체의 오류, 실제 파괴, 접촉만의 문제라고 단정하지 않는다. 메시 독립성은 미확보다. 따라서 새 코드도 현재는 설계용 최종판이 아니다.

검토 대상은 `ground_modeling_insight_updated.py`, `insight_motion.py`, `ground_hybrid`, 최종 재료 패키지, `ring_foundation_rc.py`, `dome_in_mars_tuned.py`, 이전 통합 코드다. 수정의 실행 경로는 **새 통합 진입점과 날짜가 붙은 공용 지반·재료 모듈**이다. 과거 독립 실행 파일까지 소급 변경한 것은 아니다.

## 4. 재료 코드 검토

두 카탈로그는 총 29개 고유 record를 포함하며, 중복 ID9개는 공통 숫자 상수와 법칙의 충돌을 검사했다. 밀도·E·G·K·ν의 기본 범위와 등방 탄성 관계, Steel02 항복·경화 파라미터, Concrete02 부호·압축 연화 순서, PDMY 계수와 표면 수, CFRP 가정 횡등방 compliance 양정성, 출처 식별자 참조를 검사한다. **이 검사는 계수가 실제 재료를 맞춘다는 증거가 아니다.**

- S355 coupon은 HEM320 웹 시편에서 얻은 단축 반복 모델이다. SHS에 전용한 것은 가정이며, 일반 S355 전체/용접/국부좌굴/접합부/다축 파괴로 확대하지 않는다.
- C30/SD400은 명목 비구속 prototype다. RC 단부 HingeRadau와 명시적 힌지 길이로 수치 이산화를 제한하지만, 실제 배근·구속·정착·전단·연화 객관성이 확보된 것이 아니다. 링 기본 12개 보의 형상/힌지 민감도도 남았다.
- 화성 JEZ-1은 직접전단 강도와 가정 E/ν/ψ를 조합했다. 일정 탄성강성 DP가 실제 압력 의존 Gmax·G/Gmax·감쇠 곡선·반복 다짐·액상화를 보정한 모델은 아니다.
- duricrust 물성은 얕은 지반 bulk 파동 물성의 전용이며 0.2 m crust만의 정적 E가 아니다. 적용 주파수 차이와 두께/강성 불확실성을 함께 검토해야 한다.
- 기반암 탄성 아날로그는 절리·인장균열·압괴를 포함하지 않는다. 지반 각 층의 완전 부착도 가정이다.
- CFRP 시험 평균 강도, 소결 레골리스 압축 평균강도는 허용강도가 아니다. 손상·박리/인장파괴는 별도 모델·자료가 필요하다. 차폐용 느슨한 레골리스에 구조 인장·휨 강성을 주지 않는다.

지반 강성 0.5/1/2배 검토 시 **세 경우에 같은 입력 대역·격자**를 사용해야 한다. 각 경우마다 필터 상한을 바꿔 수렴시키면 강성 민감도와 입력 변경이 혼합된다. 가장 느린 파속 경우를 만족하도록 공통 격자/대역을 먼저 정한다. 새 CLI `--ground-stiffness-factor`는 E/G/K만 같이 바꾸고 강도는 바꾸지 않는다.

## 5. 변경 사항 전체 목록

1. 날짜가 붙은 통합 진입점·지반 모듈·재료 감사 모듈·회귀검사를 추가했다. 원본 계수/생성기/패키지를 덮어쓰지 않는다.
2. 두 카탈로그의 파라미터 범위·일관성·중복 충돌·출처 참조 검사와 SHA-256 기록을 추가했다.
3. 감사된 append-only 지반 생성 wrapper를 추가해 사용 재료·요소 형상비·질량 진단을 기록한다.
4. 기본 인터페이스를 기존 tied에서 contact로 바꾸고 tied를 기준 비교 옵션으로 유지했다.
5. 기본 측면 롤러 대신 국부 점성 측면을 도입했다. 저면 구속은 유지한다. `--boundary fixed-box`로 이전 형태를 비교할 수 있다.
6. 측면 구속을 제거할 때 정적 지지 반력을 외력으로 보존하고, **새 하중을 영증분 정적 단계에서 commit한 다음** Newmark를 초기화하도록 했다. 이 과정이 없으면 새 가상 경계의 무입력 초기 가속도 오류가 발생함을 검사에서 발견·수정했다.
7. 정적 ramp를 하중계수·힘 잔차 기준, 제한된 알고리즘/증분 재시도 및 최종 영증분 재평형으로 처리한다. 물성/허용오차 완화는 없다.
8. 물리적 지반 지지점의 힘·모멘트 잔차를 추가 기록한다. 접촉 보조 회전 반력의 영향 때문에 접촉의 모멘트 잔차는 진단값이고 tied에만 엄격 gate를 적용한다.
9. 기본 입력 상한을 2→1 Hz로 바꾸고 공간/시간 대역 gate를 추가했다. **입력 자체가 바뀌었으므로 이전 결과와 같은 조건 비교가 아니다.**
10. 기본 적분 간격을 0.1→0.05초로 줄였다. 입력 Path는 0.1초이므로 중간값은 선형 보간되며 20 Hz 원신호의 전체 대역이 복원되는 것은 아니다.
11. 기본 평가2초 이전의 실제 파형5초를 적분한다. `--quick`은 선행1초/평가1초다. 명시한 `--warmup`/`--duration`이 우선한다.
12. 평가 구간에는 별도 taper를 곱하지 않으며 선행 시작 부분만 smoothing한다. 요청 구간을 기록 길이에 맞춰 조용히 자르는 대신 범위 오류를 반환한다.
13. 평가 시작 source 시간·선행/평가 구분·단위 가정·원본 hash를 보존하고, 평가 구간 극값만 별도 요약한다. warm-up 행은 CSV에 남지만 평가 peak에 합치지 않는다.
14. `--target-pga`로 벡터 PGA 기반 가상 입력을 지정하고 실제 배율·화성 g 비율을 기록한다. `--motion-scale`과 비기본 동시 사용을 거부한다.
15. 적분 실패 시 최대6회 이분하고 실패 구간을 누락하지 않는다. source Path dt와 적분 dt는 별도로 기록한다.
16. 전체 지반 절점의 변위 증분을 검사한다. 예전 surface-only 최대와 표본 집합이 다르다.
17. 기초의 유한 회전·병진 적합을 제거한 전체 돔 잔차를 출력한다. 이전의 꼭대기−기초 평균 병진 값과 다른 지표다.
